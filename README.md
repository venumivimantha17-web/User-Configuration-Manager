# User Configuration Manager

A Python-based User Configuration Manager designed to help users easily manage their personal settings and preferences. The project provides simple functions to add, update, delete, and view configuration settings such as themes, languages and notification preferences.

## Features

- Add new user settings
- Update existing settings
- Delete settings
- View current configurations
- Simple and easy-to-use Python functions
- Dictionary-based configuration management

## Technologies Used

- Python
- Dictionaries
- Tuples
- Functions

## Project Purpose

This project demonstrates fundamental Python programming concepts, including functions, dictionaries, tuples, key-value data management, and basic configuration handling.
